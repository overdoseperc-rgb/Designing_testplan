## Содержание

- Jupyter Notebook только с сохранёнными результатами выполнения тестов четырёх заданий.
- `functions.py`: is_even, calculate_area, classify_triangle.
- `strings.py`: функции КТ №2 варианта 1 из Study_of_fixturesV1.
- `tests/`: параметризованные тесты строк и функций.
- `tests/database/`: тесты SQLite и отдельная локальная фикстура БД, как в принятой КТ №2.
- `pytest.ini`: настройки из принятой КТ №2.
- `requirements.txt`: зависимости для запуска.

Все **117 тестов успешно пройдены**. Реальный вывод pytest находится в ячейках notebook.

## Загрузка на GitHub

1. Распакуйте архив в отдельную папку.
2. Создайте репозиторий на GitHub.
3. Выберите **Add file → Upload files** и загрузите содержимое распакованной папки, сохранив структуру `tests/`.
4. Нажмите **Commit changes**.
5. Для сдачи отправьте ссылку на notebook в репозитории.

Загружать сам ZIP вместо содержимого не требуется. Архивы исходных работ для запуска не нужны.

## Запуск тестов

Требуется Python 3.10 или новее. Из корня проекта:

```shell
python -m pip install -r requirements.txt
python -m pytest tests -v
```

## Открытие notebook

```shell
python -m jupyterlab
```
